Healthcare Datasets - Primary Task Brief

Objective:
Build a clear and reproducible workflow for data analysis and baseline prediction of Test Results.

Target:
Test Results (multi-class):
- Normal
- Abnormal
- Inconclusive

Core requirements:

1) Data loading
- Use project-relative path: healthcare_dataset.csv
- Avoid machine-specific paths

2) Data validation
- Confirm all required columns exist
- Parse Date of Admission and Discharge Date
- Check missing values and basic category consistency

3) Exploratory analysis
- Dataset size, column types, null counts
- Class balance for Test Results
- Distribution of Age and Billing Amount
- Top categories for Medical Condition, Hospital, Insurance Provider

4) Baseline model
- Train a simple classifier for Test Results
- Use only features available at or before admission time
- Report accuracy and class-wise precision/recall/F1

5) Reproducibility
- Keep scripts in scripts/
- Keep dependencies in requirements.txt
- Provide command examples in README.md

Recommended commands:

python scripts/validate_dataset.py
python scripts/eda_summary.py
python scripts/train_baseline.py
